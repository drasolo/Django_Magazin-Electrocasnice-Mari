# Django_Magazin-Electrocasnice-Mari

Magazin online de electrocasnice mari (frigidere, mașini de spălat, cuptoare, plite, hote), proiect pentru cursul DAW.

## Pornire

```
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Site-ul pornește la http://127.0.0.1:8000/.
